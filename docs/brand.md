# Cursourcing brand assets

**Your Codex just hired Cursor.**

Tokenmaxxing for the Astra × Grok era: put available Cursor capacity to work while Codex plans, coordinates, and reviews.

The icon combines a C with a pointer to suggest handing off work. Vermilion orange, warm white, and black carry through the cover and plugin card. The mark is an original Cursourcing emblem, independent of OpenAI's and Cursor's official logos.

The PNG assets were created with the built-in image generation tool. The plugin manifest uses `assets/icon.png` for its logo and composer icon. Both language editions of the README use `assets/hero.png`.

## Generation prompts

### Icon refinement

An initial C-plus-pointer concept was refined with this prompt:

> Edit this Cursourcing logo into a finished flat app icon. Preserve the exact C-plus-cursor silhouette and composition. Replace ALL transparency and black surroundings with one perfectly flat, opaque, edge-to-edge orange background #F35B35. The entire C and pointer must be a single flat off-white #FFF9F1 fill. Remove every orange outline, shadow, glow, grain, gradient, texture, extrusion and colored halo. Clean sharp geometric edges with ordinary smooth antialiasing only. Square 1024x1024, mark centered with 18 percent clear margin on each side. No text. The output must be completely opaque, a white symbol printed on a solid orange square.

### Cover

The final icon was supplied as the visual reference:

> Use case: ads-marketing. Create a polished developer-tool GitHub README cover and share card, landscape 1600 by 800, exactly 2:1. Input image is the Cursourcing brand icon reference: preserve its orange and off-white C-plus-pointer silhouette. This is a new wide brand graphic, not a mockup. Background warm ivory #F7F5EF, crisp ink black typography #191919 and vermilion #F35B35. Swiss editorial typography with restrained developer-tool personality, generous 70px safe margins, exceptionally clean flat design, precise typographic hierarchy. Top left: a small orange square icon using the reference, next to brand name spelled exactly 'Cursourcing'. Left two-thirds: a huge bold three-line headline spelled exactly 'Your Codex' on line 1, 'just hired' on line 2, 'Cursor.' on line 3. Only the word Cursor is orange, the other lines black. Upper right: a simple small pill 'TOKENMAXXING'. Right third: two confident stacked rectangular cards with a thin connecting arrow pointing down. Top card ivory with black border: big text 'Codex', smaller 'GPT-6 Astra', bottom label 'Plan + review'. Bottom card orange with ivory text: big text 'Cursor', smaller 'Grok 4.6', bottom label 'Execute'. Bottom footer separated by a fine rule: left text 'Put your spare Cursor capacity to work.'; right text 'cogine-ai/cursourcing'. Render all specified text exactly, no other text. No fake UI screenshots, no model or company official logos, no 3D, no gradients, no textures, no glow, no graphs with invented usage data. Ready to publish, not a design board.
